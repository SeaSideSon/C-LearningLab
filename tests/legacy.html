{ } Pointer field guideThe core rules
&x
The address of the object x.
p
An address stored in a pointer variable.
&p
The address of the pointer variable itself.
*p
The object reached by following p’s address.
tab[i]
The same element as *(tab + i).
p + 1
The next element of the pointed type.
C passes arguments by value, including pointer values. A copied address can still reach the caller’s object.
Only dereference a pointer when it refers to a valid object of the right type. Uninitialized pointer values are shown as “uninitialized” and are never followed here.
